# AI-POWERED-COPY-TRADING-ROI-ANALYSIS


## Overview

This project analyzes cryptocurrency trading activity and ranks trader accounts based on their overall performance. The system processes raw trading history data, calculates key financial metrics, and generates a leaderboard of the best-performing accounts.

The objective is to identify traders who demonstrate strong profitability, consistency, and risk-adjusted returns using quantitative financial metrics.

---

## Dataset

The dataset contains cryptocurrency trading records for multiple trader accounts.

### Key Attributes

* Port_IDs (Unique Trader ID)
* Trade Timestamp
* Trading Symbol (BTC, ETH, SOL, DOGE, FIL, ETC, etc.)
* Buy/Sell Side
* Trade Quantity
* Trade Price
* Realized Profit
* Position Type (LONG/SHORT)
* Trading Fees

---

## Project Workflow

### 1. Data Cleaning

* Handled missing values
* Converted trade history from string format into structured Python objects
* Removed invalid records
* Prepared data for analysis

### 2. Trade History Flattening

* Extracted nested trade information
* Converted complex trade history into a tabular format
* Preserved account identifiers for account-level analysis

### 3. Feature Engineering

Calculated important financial metrics for each trader:

* Total Investment
* Total Profit & Loss (PnL)
* Return on Investment (ROI)
* Win Rate
* Sharpe Ratio
* Maximum Drawdown (MDD)
* Total Positions
* Winning Positions

### 4. Trader Ranking Algorithm

A weighted scoring model was developed using:

Score =
0.30 × ROI +
0.25 × Total PnL +
0.20 × Sharpe Ratio +
0.15 × Win Rate +
0.10 × (1 − MDD)

Accounts are ranked according to their weighted performance score.

### 5. Visualization & Insights

The project includes:

* ROI Distribution Analysis
* Win Rate Distribution
* ROI vs Win Rate Scatter Plot
* Sharpe Ratio Analysis
* Correlation Heatmap
* Top Trader Identification

---

## Financial Metrics Used

### Return on Investment (ROI)

Measures profitability relative to invested capital.

### Win Rate

Percentage of profitable trades.

### Sharpe Ratio

Measures risk-adjusted return.

### Maximum Drawdown (MDD)

Measures the largest decline from a portfolio peak.

### Total PnL

Overall profit generated by a trader.
